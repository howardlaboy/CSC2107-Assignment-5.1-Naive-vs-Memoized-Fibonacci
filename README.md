# CSC2107 Assignment 5.1
## Naive vs Memoized Fibonacci

This repository contains the source code and experimental graphs for CSC2107 Design and Analysis of Algorithms Assignment 5.1.

### Contents

#### Source Code

- Fib_Implementation_One.py
  - Verification that both algorithms produce the same Fibonacci values from n = 0 to 20.

- Algo_A.py
  - Plain recursive Fibonacci implementation and experiments.

- Algo_B.py
  - Memoized Fibonacci implementation and experiments.
  - Includes recursion-limit and iterative solutions for Part 4.

- check.py
  - Displays Python recursion limit.
